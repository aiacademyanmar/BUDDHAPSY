# Buddha Psychology Care V1.7.2

Android Kotlin/Jetpack Compose prototype with twenty screens, a separate PHP/MySQL staging backend, and GitHub Actions debug APK pipeline.

**Not a clinical product.** No live patient data or production credentials. Real doctor verification, privacy review, integration tests and release approval required before use.

See `.github/workflows/build-apk.yml` for CI. The debug APK (once the CI actually succeeds) is for non-clinical testing only.
